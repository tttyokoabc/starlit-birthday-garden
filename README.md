# 把星星送到你身边 · 星光花园

这是一份采用 **GPT-6 Astra** 完成、用于赠送女朋友的生日礼物的**公开开源版本**。原作是我今年完成的一款把我和她的共同回忆、照片、生日信和现实礼物串联起来的绘本式 2D 小游戏。

公开版已移除原作中的私人称呼、生日日期、真实照片、个人经历、具体礼物和私人信件，替换为通用故事模板、六张原创 SVG 示例插画和三件示例礼物。这里的文案不代表任何人的真实经历。你可以用它制作自己的生日惊喜。

## 开始游玩

1. 下载整个项目（GitHub 页面中选择 **Code → Download ZIP**），并完整解压。
2. 用桌面版 Chrome 或 Edge 打开 `index.html`。
3. 点击邀请开始游戏。无需安装依赖、启动服务器或连接网络。

方向键或 **WASD** 移动，靠近发光处按 **E** 互动。选项、相册和继续按钮使用鼠标点击。右上角可切换音乐与全屏，照片可点击完整查看。

游戏以约 8–12 分钟的自然阅读与探索为设计目标，实际时间取决于阅读速度，不含拆礼物时间；没有强制等待、失败惩罚或倒计时。目前面向电脑键盘与鼠标，未实现手机触屏移动。没有自动存档，刷新或关闭页面会重新开始。

## 旅程内容

| 章节 | 互动 | 解锁 |
| --- | --- | --- |
| 相遇花园 | 为三朵花浇水 | 两页相册、相遇寄语、一束花的示例礼物 |
| 陪伴小屋 | 阅读来信，选择回应 | 两页相册、陪伴寄语、一本书的示例礼物 |
| 心愿湖畔 | 点亮三盏湖灯，选择心愿 | 两页相册、未来寄语、手写卡片的示例礼物 |
| 生日庭院 | 集齐三颗星星 | 蛋糕、生日信、完整回忆相册 |

选择改变即时对白，最终汇入同一个温柔结局。礼物先作为童话道具出现，再揭晓实物；此时游戏暂停，收到礼物后点击“收到啦，继续旅程”再前进。通关后可以回看照片、礼物与信件，也可以重新开始。

## 换成你的故事

所有个人内容集中在 `content.js`。用文本编辑器打开，修改后保存，再刷新网页即可；不需要修改游戏逻辑。

| 字段 | 用途 |
| --- | --- |
| `recipient` / `sender` | 收礼人 / 送礼人的称呼 |
| `birthdayLabel` | 生日日期或一句短祝福 |
| `coverIntro` / `invitation` | 首页文字和邀请信 |
| `chapters[].subtitle` / `memory` | 每章标题下的小字与回忆段落 |
| `chapters[].photos` | 图片路径、图注 `caption`、替代文本 `alt` |
| `letterIntro` / `wishIntro` / `choices` | 选项前的文字、选项和回应 |
| `chapters[].gift` | 礼物道具、实物名称、揭晓与寄语 |
| `ending` | 终章标题、引言和生日信段落 |

文字里的 `{recipient}` 和 `{sender}` 会自动替换为配置中的称呼。保留三个章节的顺序、章节 `id`、照片 `id` 和选项 `id`；引号、逗号与方括号需要保持合法 JavaScript 格式。双引号里的换行写作 `\n`。

### 替换照片

把图片放入 `assets/photos/`，然后在对应的 `photos` 项中填写相对路径，例如：

```js
{ id: "photo-1", src: "assets/photos/memory-01.jpg",
  caption: "在这里写下这张照片的故事。", alt: "简要描述照片内容" }
```

支持浏览器可显示的 JPG、PNG、WebP、SVG 等格式。图片保留原始比例，横图和竖图都可以点开完整查看；找不到资源时会显示占位卡片，仍能继续旅程。文件名大小写必须与路径一致，以便在 GitHub Pages 等环境正常加载。

`01.svg` 至 `06.svg` 是随项目提供的原创示例插画，可以保留或替换。公开仓库中的素材能被下载：加入自己的照片、称呼或私人故事后，请将个性化版本保存在本地或私有仓库。`.gitignore` 不会自动识别并隐藏 `content.js` 或 `assets/photos/` 中的个人内容。

### 调整礼物

```js
gift: {
  enabled: true,
  symbol: "✉",
  token: "寄往明天的星光信封", // 童话道具
  realName: "一张手写卡片",    // 现实礼物
  reveal: "揭晓礼物时的文字。",
  message: "交到对方手里时想说的话。"
}
```

把任意一章的 `gift.enabled` 改为 `false`，即可只展示回忆与寄语，跳过该章实物送礼环节；星星和后续流程照常解锁。默认三个礼物均为演示配置，正式赠送前请替换或关闭。

## 开发与验证

运行游戏本身不依赖 Node.js；只有自动测试需要 Node.js（建议 22 或更新版本）与 npm。

```sh
npm ci
npm run check
npm test
npm run test:browser
```

浏览器测试默认使用已安装的 Microsoft Edge，直接访问本地 `file://` 页面，并拦截 HTTP/HTTPS 请求以检查离线运行。没有 Edge 时，可以使用 Playwright Chromium：

```sh
npx playwright install chromium
npm run test:browser:chromium
```

也可以通过环境变量 `BROWSER_PATH` 指定本机 Chrome / Edge 可执行文件的完整路径。首次安装测试依赖或 Chromium 需要联网，游戏游玩无需联网。测试截图仅保存在被 Git 忽略的 `test-results/`。

测试覆盖章节顺序、奖励去重、礼物暂停、无实物礼物、不同对白、结局回看、重新开始、失焦停止移动、对话禁止移动、横竖图、缺图回退、静音、全屏和常见桌面窗口尺寸。自动测试不能代替对个人文案与实际送礼节奏的人工确认。

项目结构：

```text
index.html       页面入口和对话容器
styles.css       页面、相册和对话样式
content.js       可替换的故事内容
state.js         章节进度、解锁与重置
game.js          Canvas 场景、输入、对话与合成音乐
assets/photos/   六张公开示例插画
tests/           内容检查、状态测试和浏览器流程测试
```

使用原生 HTML、CSS、JavaScript，Canvas 绘制场景，HTML 展示中文文字与图片，Web Audio 合成轻柔音乐。不使用第三方音乐文件，没有账号、云端存档、统计或运行时网络请求。`package.json` 的 `private: true` 仅防止误发布到 npm，不影响 GitHub 开源。

## 放到 GitHub

为这个公开版新建仓库，只上传本目录的源码和 SVG 素材即可。不要复用包含私人素材的旧仓库历史。`node_modules/`、`test-results/` 和本地压缩包已通过 `.gitignore` 排除。

这是静态网页，也可将新仓库的根目录部署到 GitHub Pages。部署前确认内容都是愿意公开的素材；本项目没有登录或访问控制。
